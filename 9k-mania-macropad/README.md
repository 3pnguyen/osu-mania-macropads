## ✨ About

This macropad was created as a commision by a friend who is a much better player than me. Playing harder difficulties means more killer specs. Such as, hall effect switches, rapid trigger, and an 8K polling rate. They also like to expand their horizons, playing 5K, 6K, and 7K as well. This project also features a full casing as well. To truly support these demands, I chose the Teensy 4.0 as the brain. 

This project is a direct contrast from my personal 4K macropad.

Since this is hall effect, calibration is required. Using a serial web interface like [serialmonitor.org](https://serialmonitor.org) and holding down the dedicated push-button enters calibration mode.
